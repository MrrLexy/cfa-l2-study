# CFA Level II Study

An unofficial study guide for the CFA Level II exam: the study **Path** (46 sections with 900 practice questions and a review step after each), the **LOS cards** (all 369 learning outcomes, each with an answer, and note cards to study on screen, print or download as PDFs), the **Guide** (a walkthrough of every module, with concepts and formulas), the **Map**, the **Case studies** (exam-style item sets) and **Rapid fire** (one question after another by topic, with the full explanation straight after each answer).

**This copy is passcode-protected.** The study material in it is encrypted. Open the site, type a username and the passcode you were given, and tick "Keep this device unlocked" so you only type it once per device.

It runs entirely in your browser. There is no account and no server: open the site, type a username, and study.

## Using it
1. Open the site and type a **username**. A new name starts a new profile; the same name opens the same one. There is no password.
2. Start with the **Path**: each section is a set of practice questions, a review of what they covered, and a second set. The **LOS** tab lists every learning outcome with a tick box,
   an answer and note cards. The **Guide** has a walkthrough of each module.
3. Your progress is saved in your browser, under your username, so each username keeps its own.

## Profiles and progress
- Progress lives in the browser on the device where you made the profile. To move it to another device, open the profile menu (top right), choose **Export my progress**, then
  **Import progress** on the other device. Importing merges, and the newer copy of each section wins.
- Clearing a browser's site data erases the profiles on that device, so export now and then.
- A username only keeps progress apart; it is not security.

## On a phone or tablet
Open the site in Safari (iPhone and iPad) or Chrome (Android), then Share > Add to Home Screen (or the browser menu > Install app). After the first visit it also opens offline.
